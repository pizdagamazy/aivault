# AIVAULT — сайт + админ-панель (первый этап)

## Файлы
- `index.html` — текущий публичный сайт.
- `admin.html` — панель управления портфолио и отзывами.
- `aivault-config.js` — общие настройки Supabase для сайта и админки.
- `supabase-setup.sql` — таблицы и политики безопасности для Supabase.

## 1. Создай базу данных
1. Открой https://supabase.com и создай проект.
2. Запомни пароль базы данных в безопасном месте.
3. В Supabase открой **SQL Editor → New query**.
4. Открой `supabase-setup.sql`, замени ВСЕ вхождения `YOUR_LOGIN_EMAIL@example.com` на email, который будешь использовать для входа в админку.
5. Вставь весь SQL в редактор и нажми **Run**.

## 2. Получи публичные ключи
В Supabase открой **Project Settings → API** (или **Connect**) и скопируй:
- Project URL
- anon/public key

Никогда не используй `service_role` key в браузере и не отправляй его никому.

## 3. Подключи конфигурацию
Открой `aivault-config.js` в редакторе и замени `PASTE_SUPABASE_PROJECT_URL_HERE` и `PASTE_SUPABASE_ANON_PUBLIC_KEY_HERE` своими значениями из Supabase. Сохрани файл. Используй только anon/public key.

## 4. Загрузи файлы в GitHub
В репозитории `aivault` нажми **Add file → Upload files**, загрузи `index.html`, `admin.html`, `aivault-config.js`, `supabase-setup.sql`, `README.md`, затем нажми **Commit changes**.

## 5. Опубликуй на Netlify
1. Открой https://app.netlify.com/ и подключи свой GitHub.
2. Добавь новый сайт из существующего репозитория `aivault`.
3. Build command оставь пустой, publish directory укажи `.`.
4. Нажми Deploy.

## 6. Подключи админку
Открой опубликованный адрес `/admin.html`.
Если конфигурация заполнена правильно, форма подключения пропустится автоматически. Открой `/admin.html`.
Создай аккаунт с тем email, который вписал в SQL, и задай надёжный пароль.
Если включено подтверждение email, подтверди его из письма и войди.
После входа добавляй проекты, загружай изображения и модерируй отзывы.

## Важно
- Эта первая версия админки управляет портфолио и отзывами.
- Главная страница читает опубликованные работы и одобренные отзывы из Supabase. Новые работы и одобренные отзывы будут показываться посетителям автоматически.
- Не используй фальшивые отзывы как настоящие.
